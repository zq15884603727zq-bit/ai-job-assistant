# 测试用例：示例 JD

## 职位名称
高级 Python 后端工程师

## 职位描述

负责公司核心业务系统的后端设计与开发，参与系统架构设计，编写高质量可维护的代码。

## 岗位职责
1. 参与后端服务的架构设计与开发
2. 编写高质量、可维护的 Python 代码
3. 与前端团队协作完成 API 接口设计
4. 参与代码评审和技术方案讨论
5. 线上问题的排查与修复

## 任职要求
1. 统招本科及以上学历，计算机相关专业
2. 3 年以上 Python 后端开发经验
3. 熟悉 Django / FastAPI 等主流框架
4. 熟悉 MySQL / PostgreSQL / Redis
5. 了解 Docker / Kubernetes 容器化部署
6. 良好的沟通能力和团队协作能力

## 加分项
- 有微服务架构设计经验
- 了解 AI / ML 相关技术
- 有开源项目贡献经验

## 薪资范围
25K - 40K * 15 薪

## 工作地点
北京 · 望京
